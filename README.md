# Assignment 1 Portfolio

## Project Description

This project is a simple personal portfolio website built for the first assignment in SWE363. It presents information about the student, highlights selected projects, and demonstrates responsive design and basic JavaScript interactivity.

## Included Projects

- Classroom Reservation System (Java)
- JavaScript Game

## Setup Instructions

1. Download or clone the repository.
2. Open the project folder.
3. Launch `index.html` in any modern browser.
4. If you want to use a local server, run:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000` in the browser.
