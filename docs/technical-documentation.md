# Technical Documentation

## Project Overview

This project is a responsive personal portfolio website created as the first assignment for SWE363. The site showcases a student developer profile, highlights projects, and includes a contact form with a simple interactive UI.

## Project Structure

- `index.html` — Page structure and content
- `css/styles.css` — Styling, layout, responsive design, and dark mode
- `js/script.js` — Greeting message, theme toggle, and contact form interaction
- `docs/ai-usage-report.md` — Explanation of AI usage and responsible use
- `README.md` — Project setup and summary

## Features Implemented

- Hero section with introduction and call-to-action buttons
- About section with skills and profile summary
- Projects section with two project cards
- Contact section with a working form interaction
- Responsive layout for desktop, tablet, and mobile
- Dark/light theme toggle using JavaScript and localStorage
- Dynamic greeting based on the current time of day

## Design Notes

The layout uses CSS Grid and Flexbox to create a modern, clean portfolio experience. The design includes a light/dark theme and responsive breaks to ensure the page remains readable on smaller screens.

## Implementation Notes

The JavaScript file adds small interactive features without requiring a backend. It checks the current time to generate a personalized welcome message and toggles the theme while storing the user preference locally.

## How to Run

1. Open the project folder in a browser.
2. Open `index.html` directly in the browser, or run a local web server if preferred.
3. Ensure the project files remain in the same folder structure for correct linking.
