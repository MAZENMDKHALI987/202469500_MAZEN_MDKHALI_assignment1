# AI Usage Report

## Tools Used & Use Cases

- GitHub Copilot: Used to generate the initial structure of the portfolio website, suggest HTML sections, and help improve the CSS and JavaScript for the theme toggle and form interaction.
- ChatGPT / AI assistance: Used to refine the project content, shape the portfolio messaging, and review the readability and structure of the documentation.

## Benefits & Challenges

Using AI helped speed up the development process by generating clean code patterns and offering quick ideas for layout and styling. It also simplified the documentation workflow by helping draft the README and technical notes.

The main challenge was making sure the final output matched the assignment requirements and fit the specific student project context. AI suggestions needed review and adjustments to make them accurate, original, and aligned with academic integrity.

## Learning Outcomes

From using AI, I learned how to structure a simple portfolio website more efficiently, organize sections logically, and combine HTML, CSS, and JavaScript for a responsive user experience. I also improved my understanding of how design and interactivity can work together in front-end projects.

## Responsible Use & Modifications

I reviewed each AI-generated suggestion carefully and changed the content to reflect my own project information, goals, and coursework. I made sure the final solution was original, correct, and appropriate for the assignment. I did not rely on AI-generated text without checking it for accuracy or relevance.
